# Contributing Guidelines
## Step 1: Clone the Repository
Clone this repository to your local machine using `git clone https://github.com/your-username/your-repo-name.git`
## Step 2: Create a New Branch
Create a new branch for your feature using `git checkout -b feature/your-feature-name`
## Step 3: Commit Changes
Commit your changes with a meaningful message using `git commit -m 'your commit message'`
